Why ClearLens?

🔍

Hybrid RAG

FAISS vector search + BM25 keyword + cross-encoder re-ranking for maximum relevance.

🧠

Multi-Model AI

GPT-4o-mini reasoning, Gemini Flash OCR, Whisper STT, BERT embeddings.

🔒

User Isolation

JWT authentication. Every user sees only their own history and data.

⚡

Local Detection

Lightweight risk detector runs in-browser. No cost for safe content.

📊

Trust Score

Calibrated confidence based on source reliability, contradictions, and evidence coverage.

📝

Transparent

Every verdict includes source links and reasoning. Users verify the fact-checker.

API Endpoints

POST /auth/register
Create a new account
POST /auth/login
Login and receive JWT token
POST /api/v1/analyze
Analyze a YouTube Short for misinformation
GET /api/v1/history
Get your analysis history
POST /api/v1/feedback
Submit feedback on a verdict
GET /api/v1/health
Server health check
